# cleanflhin.com

Site web de Clean Flhin, hébergé sur GitHub Pages avec le domaine cleanflhin.com.

- `index.html` : page d'accueil
- `app/` : application web (et `CleanFlhin.apk` pour Android)
- `mentions-legales/`, `confidentialite/`, `conditions/` : pages légales
- `CNAME` : domaine personnalisé (ne pas supprimer)

Les fichiers sont générés à partir des maquettes ; les sources de génération sont dans le dépôt privé `clean-flhin-app` (dossier `web/`).
